== Code (ClimaAtmosResiDyn-c1c, energy_source_tags.jl) ==
- Loss: min(Δ,0)·φ_k for every tag (609-613, 632-636); φ = clamp(T/E,0,1), 0 if E<=0 (430-432).
- Gains: M_k·max(Δ,0) (632-634); pure region masks sum to 1.
  => per bracket, R = E - Σ region tags changes by -(R/E)·Δ⁻ (untagged and
     overclaimed alike, while no φ clamps at 1). Gains leave R unchanged.
- Repair keeps the partition sum (673-675), so it leaves R unchanged unless all
  region tags are zeroed. Source-tag clip adds energy outside R (689-690).
- Audit transport: shares divided by the partition's sum of clamped shares
  (831-833, 850-878, 1240-1330) => the partition carries exactly the parent's
  flux, so R is NOT transported under the audit. Under tracer transport (and the
  EDMF eddy diffusion before C1c) R is advected/diffused as a tracer.
